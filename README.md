# Homebrew Tap for emmesbef

This repository contains [Homebrew](https://brew.sh/) formulae and casks for apps by emmesbef.

## Available Casks

### clockify-jira-sync

Desktop app to sync Clockify time entries with Jira worklogs.

```bash
brew install --cask emmesbef/tap/clockify-jira-sync
```

This installs the app to `/Applications/clockify-jira-sync.app` and automatically removes the macOS quarantine flag (no Gatekeeper warning).

To update:

```bash
brew upgrade --cask clockify-jira-sync
```

To uninstall:

```bash
brew uninstall --cask clockify-jira-sync
```
