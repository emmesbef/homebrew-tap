# Homebrew Tap for emmesbef

This repository contains [Homebrew](https://brew.sh/) formulae and casks for apps by emmesbef.

## Available Casks

### jirafy-clockwork

Desktop app to sync Clockify time entries with Jira worklogs.

```bash
brew install --cask emmesbef/tap/jirafy-clockwork
```

This installs the app to `/Applications/jirafy-clockwork.app` and automatically removes the macOS quarantine flag (no Gatekeeper warning).

To update:

```bash
brew upgrade --cask jirafy-clockwork
```

To uninstall:

```bash
brew uninstall --cask jirafy-clockwork
```
